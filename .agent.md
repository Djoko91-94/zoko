# Zokora Project Agent

This custom agent is designed to support work in the `zokora-1` workspace, with a focus on:

- React + Vite frontend development in `src/`, `public/`, and related config files
- Express backend logic in `server.js`
- Tailwind, PostCSS, and CSS styling workflow
- HTML/JS/CSS files at the project root, including `zoko.html`, `zoko.js`, and `zoko.css`
- Light Python utility and script maintenance when it relates to the workspace

## When to use this agent

Use this agent for tasks that are specific to this project, such as:

- fixing or extending React components and app layout
- updating build / dev configuration in `vite.config.js`, `postcss.config.js`, or `tailwind.config.js`
- adding backend routes or API behavior in `server.js`
- improving static assets, HTML pages, or UI styles

## Behavior and preferences

- Prefer workspace-local edits and minimal, targeted changes.
- Preserve existing project conventions and file structure.
- Use available package scripts from `package.json` for build, lint, and dev validation.
- Avoid introducing unrelated frameworks or external dependencies unless the user explicitly asks.

## Example prompts

- "Improve the React structure for the portfolio app and fix any lint issues."
- "Add a new Express API endpoint to `server.js` and connect it to the frontend."
- "Update `vite.config.js` for a new environment variable and make sure the app still builds."
- "Refactor `src/App.jsx` to simplify state handling and component layout."
